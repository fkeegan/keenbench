# ODP Style Guide

## Tool Capability Catalog
Use `odp_operations` for slide edits, `odp_get_styles` to inspect style descriptors, and `odp_copy_assets` to copy compatible style/layout/media assets between ODP files.

## Formatting Principles
Maintain slide hierarchy, text contrast, spacing rhythm, and visual consistency for titles, body content, and callouts.

## Worked Examples
Copy the source ODP deck, inspect styles when exact branding matters, then apply focused slide text/bullet/layout changes using `odp_operations`.
