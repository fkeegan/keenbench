# ODS Style Guide

## Tool Capability Catalog
Use `ods_operations` for sheet edits, `ods_get_styles` to inspect formatting descriptors, and `ods_copy_assets` to copy compatible formatting/theme assets between ODS files.

## Formatting Principles
Keep header/total styling consistent, preserve number/date formats, and maintain predictable alignment, widths, and spacing across sheets.
