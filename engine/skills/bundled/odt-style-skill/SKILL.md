# ODT Style Guide

## Tool Capability Catalog
Use `odt_operations` for document edits, `odt_get_styles` to inspect style descriptors, and `odt_copy_assets` to copy compatible style/layout/media assets between ODT files.

## Formatting Principles
Preserve heading hierarchy, paragraph spacing, list consistency, table alignment, and typographic tone from the source style.

## Worked Examples
Start from a copied source ODT, query styles when fidelity matters, then apply focused paragraph/table/text edits with `odt_operations`.
