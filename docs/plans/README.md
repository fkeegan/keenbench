# Plans

Implementation plans are split by lifecycle:

- `docs/plans/`: active plans (`Draft`, `Planned`, `In Progress`, `Proposed`)
- `docs/plans/implemented/`: finished plans (`Implemented`, `Completed`)

Plan filenames use `YYYY-MM-DD-<slug>.md` so chronological order is obvious in directory listings.

For detailed authoring, status, lifecycle, and link-update rules, see:

- `docs/plans/AGENTS.md`
